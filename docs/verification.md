# 2026-10-26 공개 준비 검증

이번 대표 실조회는 조달 HTTP4회로 검색5건·상세1건·수집10건, 웹 목록 HTTP2회40건·상세 HTTP1회1건입니다. 조달 부분수집 MCP isError=false, SQLite·JSONL·Excel 및 웹 HTML 원문 대조를 통과했습니다. 이전 버전과 달라진 상태·보기·링크·원문복원·옛 Excel 이름 호환은 tests/test_release.py에서 회귀합니다. 이전 실제 실패를 호출한도 도달로 덮어 성공 처리하지 않는 회귀도 포함합니다.

로컬 전체 시험과 새 환경 설치 시험을 수행한 ZIP에는 MANIFEST.json·VALIDATION.json이 포함됩니다. 공개 GitHub Actions에서도 설치·전체 시험·CLI·가상 예제를 재실행합니다. 실제 API 키 없이 실행하며 외부 실조회는 자동 반복하지 않습니다. 실조회 원문 DB·개인 환경은 공개하지 않습니다.

아래는 **0.1.0 당시의 역사 검증 기록**입니다. 당시 시험 건수를 현재 버전의 전체 시험 건수로 해석하지 마세요.

# 검증 범위

2026-10-24, Python3.12.3·Linux에서 신규 구현을 시험했습니다. 기존 다른 제품의 시험 결과는 이 제품의 근거에 포함하지 않습니다.

공개 실조회 근거 ID: `owned-books-live-20261024T080720.823310Z-a57d88d6`. 실제 고객자료·인증값·실조회 원문 DB는 예제나 ZIP에 포함하지 않습니다. 다른 OS, 다양한 실제 동적 사이트, 외부 내용이 중단 전후 바뀌는 경우의 스냅샷 동일성은 미확인입니다. 사이트의 정확한 전체건수는 null+사유로 표시하며 0으로 추정하지 않습니다.
